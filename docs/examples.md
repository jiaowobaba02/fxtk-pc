# Examples 导读

| 示例 | 看点 |
|---|---|
| ex01_hello | 按钮/标签/复选框、`fx_set_title/fx_set_bg` |
| ex02_widgets | `grid()` 键盘、滑条-进度条联动 |
| ex03_anim | `anim(1)` 画布、波形 + `fx_fill_polygon_rot` |
| ex04_edit | 输入框：框选/剪贴板/`maxlen`/滚轮 |
| ex05_scroll | 画布自绘长列表 + `fx_wheel_take` + 滚动条 |
| ex06_img | `fx_image_create` + `fx_draw_image_rot` 旋转贴图 |

运行：`./build_ex.sh ex03_anim`
