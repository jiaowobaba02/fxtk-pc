# fxtk 桌面演示（desktop）

`linux_sim/app_desktop.c` 实现了一个多标签“桌面”演示，用于验收全部控件与交互。设计基线 480×272，等比缩放铺满任意分辨率。

## 页面结构

界面顶部为 `tab` 标签栏，子页用 `page(n)` 挂载：

| 页 | 内容 | 验收点 |
|---|---|---|
| 波形 | 动画曲线 + 速度滑杆 + 开关 | `anim(1)` 每帧重绘、滑杆实时调参 |
| 图形 | 直线/圆/矩形等原语 | 绘制原语正确性 |
| 控件 | 按钮/滑杆/进度/复选 | 值变化回调 |
| 图片 | 贴图 + 缩放/灰度 | `fx_image_set_zoom`、`fx_image_grayscale` |
| 3D | 离屏画布 + 旋转体 | 离屏像素路径、`fx_draw_image_rot` |
| 输入 | 两个输入框 + 说明 | 键盘输入、Ctrl+C/V/X/A |
| 画板 | 可绘制画布 + 笔色按钮 | 触摸/鼠标拖动绘制 |
| 键鼠 | 实时键鼠状态 | **悬停坐标实时更新**、按键回显 |
| 压测 | 移动控件 + 计数 | `fx_widget_set_rect` 拖动不闪 |
| 滚动 | 60 行虚拟滚动 | 滚轮像素级平滑滚动 |
| 组件 | 列表/下拉/多字号 | 下拉向上弹、弹层滚动不越界 |
| 粒子 | 大量粒子动画 | 性能 |

## 关键交互

- **右键菜单**：任意处右键弹出顶层菜单（置顶，不被页面遮挡），含复制/粘贴等项。
- **悬停**：鼠标移动（不按下）即更新坐标，键鼠页实时显示。
- **下拉**：靠底部自动向上弹；弹层带滚动；收起无“下巴”。
- **列表**：滚轮滚动 + 点击选中，选中行高亮。
- **拖动**：压测页控件可拖动，单遍绘制不闪烁。

## 布局写法

```c
/* 像素（480 设计坐标，等比缩放） */
fx_label_new(pixel("6,36","240,56"), page(5), title("..."));

/* 百分比（0.0~1.0 浮点字符串，相对父控件） */
fx_label_new(percent("0.02,0.01","0.98,0.09"), title("fxtk 演示 · 标签页"));
```
