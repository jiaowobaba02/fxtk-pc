# 桌面扩展语义

## 焦点
- 点击输入框 = 获焦；点击其他任意控件/画布 = 失焦；
- 切换标签页时，若焦点控件不在激活页则自动失焦；
- 隐藏页控件不会被立即重绘（`widget_in_active_page` 保护）。

## 文本框
- 动态缓冲，默认不限长度；`maxlen(n)` 按**字符**计数并显示 `n/max`；
- 自动换行；拖拽可跨行框选；`Ctrl+A/C/V/X` 走**系统剪贴板**；
- `←→/Home/End` 移动光标；内容超出高度时滚轮滚动 + 右侧滚动条（可拖拇指）。

## 滚轮路由
滚轮事件命中最近的可滚动祖先：`FX_W_SCROLL` / `FX_W_TEXTEDIT` 走 `scroll_y`；
`FX_W_CANVAS` 走 `fx_wheel_take(w)`（取后清零），由画布自绘滚动。
方向约定：轮下 = 往下看（与桌面习惯一致）。

## 运行时移动控件
`fx_widget_set_rect(w,x1,y1,x2,y2)`：擦旧画新，适合动效/悬浮窗；
「压测」页用它在动画画布回调里驱动多个控件沿李萨如轨道移动。
